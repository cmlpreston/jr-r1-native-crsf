## Recent R1 implementation, already flashed

### GPS fields and blue speed mode

Independently implemented the EdgeTX CRSF convention: each all-FF field is
unavailable independently, rather than rejecting/accepting the entire GPS frame.
Fresh speed has its own timestamp, flag and packet counter; zero speed is valid.
Missing coordinates cannot move the map to near (0,0), refresh position age or
append trail points. Last known map position is retained separately. Missing
heading/satellites do not invalidate valid speed. Speed widgets/statistics work
without a position fix. Course requires valid position, heading and fresh speed
at least 1 km/h. GPS fields currently expire after three seconds.

Reference: https://github.com/EdgeTX/edgetx/blob/main/radio/src/telemetry/crossfire.cpp

Tests cover synthetic 10 Hz speed-only packets, FF fields, bad CRC, full GPS
resumption, freshness/wrap, both orientations and all widget sizes.

### RadioMaster-focused telemetry UI

Hidden old FrSky FAS voltage/current cards from Data sensor pages and new widget
source selection. Persisted source IDs remain stable, legacy FAS widgets/decoder
remain compatible. Current/energy page exposes ERS pack/current/used/remaining.
Native selector for Standard CRSF battery packet → Receiver supply or Vehicle
pack / CU01 is CUT-only and uses existing saved setting. Select Vehicle pack /
CU01 with stock receiver plus CU01. Last live diagnostics showed vehicle role;
verify after future flashes/reboots because it appeared to return to default on
one earlier flash. No deliberate persistence fix has been made for that concern.

### Independent RX supply with stock ELRS + CU01

Stock ELRS stops ordinary receiver battery 0x08 when external battery 0x08 is
detected, but still sends voltage group 0x0e source128, first ADC value in mV.
When vehicle/CU01 role is selected, R1 now uses source128 for RX supply, rounded
to decivolts. CU01 battery remains vehicle pack; CV01 remains individual cells.
Legacy receiver role preserves the earlier custom S.Port convention.
Tests cover independent values, zero CU01, malformed groups, CRC and staleness.
User confirmed the RX voltage fix works.
